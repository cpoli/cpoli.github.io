# cpoli.github.io

Personal site of Charles Poli, built with [Astro](https://astro.build) and deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `master`.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
```

Content (links, packages, papers, experience) lives at the top of `src/pages/index.astro`; styles are in `src/styles/global.css`.
